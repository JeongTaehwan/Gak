# 기획 인수 테스트

## 입력 화면

| # | 대상 요구사항 | 사전 조건 | 사용자 행동 | 기대 결과 | 확인할 거짓말 방지 조건 |
|---:|---|---|---|---|---|
| IN-01 | 1차 지원 팀 | 비공개 1차 검증 환경이다 | 입력 화면을 연다 | 팀 선택 UI에 맨체스터 유나이티드만 선택 가능하게 표시된다 | 805개 저장 팀을 지원 팀처럼 노출하지 않는다 |
| IN-02 | 팀 선택 UI | 맨체스터 유나이티드 데이터가 정상이다 | 팀 선택 UI에서 맨체스터 유나이티드를 선택한다 | 이후 화면들이 팀 ID 33의 데이터를 사용한다 | 화면별로 서로 다른 팀의 데이터를 섞지 않는다 |
| IN-03 | 공개 전 제한 | 다팀 지원이 완료되지 않았다 | 일반 사용자가 서비스에 접근하려 한다 | 일반 사용자에게 공개되지 않는다 | 미지원 팀을 선택 가능한 것처럼 보이지 않는다 |
| IN-04 | 공개 팀 범위 | 다팀 지원이 완료되었다 | 팀 선택 목록을 연다 | 유럽 5대 리그와 K리그1 남자 1부 팀만 선택 대상으로 나온다 | 컵 참가만으로 하부리그 팀을 포함하지 않는다 |
| IN-05 | 승격·강등 팀 판정 | 승격 또는 강등된 팀이 있다 | 특정 시즌의 팀 목록을 연다 | 조회 시즌에 선택 기준 대회 경기가 있는 팀만 나온다 | 현재 소속으로 과거 목록을 바꾸지 않는다 |
| IN-06 | 팀 기준의 단일 소스 | 선택 기준 대회 경기 데이터가 있다 | 같은 팀·시즌을 조회한다 | 모든 화면이 같은 파생 규칙을 사용한다 | `competition.displayed`나 저장 팀 목록을 대신 사용하지 않는다 |
| IN-07 | 선택 팀 데이터 로딩 | 팀 목록 요청이 진행 중이다 | 입력 화면을 연다 | `[미정]`인 로딩 상태가 표시된다 | 빈 목록을 실제 선택 가능 팀 0개로 단정하지 않는다 |
| IN-08 | 선택 팀 데이터 실패 | 팀 목록 요청이 실패한다 | 입력 화면을 연다 | `[미정]`인 실패 상태가 표시된다 | 실패를 선택 가능 팀 없음으로 표시하지 않는다 |
| IN-09 | 현재 시즌 자동 판정 | 여러 시즌에 치른 경기가 있다 | 입력 화면을 연다 | 치른 경기가 있는 시즌 중 가장 큰 `season`이 사용된다 | 미래 일정만 있는 시즌을 현재 시즌으로 선택하지 않는다 |
| IN-10 | 시즌 직접 선택 금지 | 현재 시즌이 자동 판정되었다 | 입력 화면을 사용한다 | 현재 분석 시즌을 임의로 고르는 UI가 없다 | 숨은 `season` 값으로 화면과 실제 분석 기간이 달라지지 않는다 |
| IN-11 | 이전 시즌 회고 진입 | 이전 조회 가능 시즌이 있다 | `지난 시즌 보기`를 누른다 | 한 칸 이전 시즌으로 이동하고 팀을 유지한다 | 현재 분석과 과거 회고를 같은 시간축처럼 섞지 않는다 |
| IN-12 | 자유 질문 | 계산된 진단 데이터가 충분하다 | 팀 부진 원인을 자유 입력으로 묻는다 | 확인된 계산·진단 데이터를 근거로 답한다 | 뉴스나 소문을 계산 근거처럼 사용하지 않는다 |
| IN-13 | 선수 문제 질문 | 특정 선수를 판단할 근거 데이터가 충분하다 | 어떤 선수가 문제인지 묻는다 | 근거가 있는 범위에서만 답한다 | 근거 없이 특정 선수를 원인으로 단정하지 않는다 |
| IN-14 | 근거 데이터 부족 | 질문에 필요한 데이터가 없다 | 자유 질문을 제출한다 | 근거 데이터 부족 상태를 알린다 | null을 0 또는 문제가 없음으로 바꾸지 않는다 |
| IN-15 | 지원 범위 밖 질문 | 질문이 지원 데이터로 분석할 수 없는 내용이다 | 자유 질문을 제출한다 | 지원 범위 밖임을 알린다 | 모델의 추측으로 답을 채우지 않는다 |
| IN-16 | 분석 처리 실패 | 질문 분석 도중 오류가 발생한다 | 자유 질문을 제출한다 | 분석 처리 실패임을 알린다 | 실패를 성공한 분석 결과처럼 표시하지 않는다 |
| IN-17 | 질문 이해 실패 | 질문의 뜻을 판별할 수 없다 | 자유 질문을 제출한다 | 질문 이해 실패임을 알리고 다시 표현하도록 요청한다 | 지원 범위 밖이나 데이터 부족으로 잘못 분류하지 않는다 |
| IN-18 | 자유 질문 분기 | 자유 질문이 입력되었다 | 질문을 제출한다 | `teamId + season`과 함께 진단 경로로 전달된다 | 예측·이동으로 분기하거나 회고 질문에 현재 시즌을 사용하지 않는다 |
| IN-19 | URL 상태 복원 | 팀·시즌·탭이 URL에 기록되어 있다 | URL을 공유하거나 새로고침한다 | 같은 팀·시즌·탭이 복원된다 | 다른 시즌이나 팀 데이터를 같은 상태처럼 보여주지 않는다 |
| IN-20 | 자동 시즌 URL | 자동 판정 시즌이 변경되었다 | 이전 URL을 연다 | URL에 고정된 시즌과 팀 상태가 재현된다 | 현재 시즌으로 조용히 바꾸지 않는다 |
| IN-21 | 부분 데이터 답변 | 일부 경기만 질문 근거 데이터를 가진다 | 자유 질문을 제출한다 | 사용한 경기 수와 전체 경기 수를 구분해 알린다 | 부분합을 전체 결과처럼 말하거나 분모를 감추지 않는다 |
| IN-22 | 미확정 경기 | 결과가 확정되지 않은 경기가 포함된다 | 자유 질문을 제출한다 | 미확정 경기를 확정 결과 계산에서 제외하거나 미확정으로 표시한다 | 미확정 결과를 무승부나 패배로 채우지 않는다 |
| IN-23 | 시간축 불일치 | 분석 시즌과 다른 시점의 정보가 존재한다 | 자유 질문을 제출한다 | 다른 시간축의 정보를 진단 근거에서 분리한다 | 현재 뉴스나 사후 정보로 과거 시즌을 판단하지 않는다 |

| IN-24 | 선택 대상이 아닌 시즌 | 선택한 팀에 조회 시즌의 선택 기준 리그 경기가 없다 | 그 시즌으로 이동한다 | 팀을 유지하고 `이 시즌에는 선택 대상 1부 리그 기록이 없습니다`라고 표시한다 | 2부라고 단정하거나 다른 팀으로 교체하지 않는다 |
| IN-25 | 컵 경기만 있는 시즌 | 선택 기준 리그 경기는 없고 컵 경기만 있다 | 타임라인을 연다 | 컵 경기만 표시하고 부분 데이터임을 밝힌다 | 컵 일부를 시즌 전체처럼 표시하지 않는다 |
| IN-26 | 리그 기록 없는 진단 | 선택 기준 리그 경기는 없고 컵 경기만 있다 | 진단을 연다 | 판정 불가로 표시한다 | 컵 경기만으로 시즌 전체를 진단하지 않는다 |
| IN-27 | 리그 기록 없는 순위표 | 조회 시즌에 선택 기준 리그 경기가 없다 | 순위표를 연다 | 해당 시즌 순위표 없음 상태를 표시한다 | 최신 시즌 표로 대체하지 않는다 |
| IN-28 | 시즌별 예측 기록 | 여러 시즌 예측이 있다 | 과거 시즌 기록을 연다 | 조회 시즌 기록만 집계한다 | 다른 시즌 기록을 분모에 섞지 않는다 |
| IN-29 | 가장 오래된 시즌 경계 | 더 오래된 조회 가능 시즌이 없다 | 회고 화면을 연다 | 버튼이 비활성화되고 `이전 시즌 데이터가 없습니다`를 표시한다 | 팀의 1부 이력만으로 전체 보유 기간을 줄이지 않는다 |
| IN-30 | 현재 시즌 복귀 | 과거 시즌을 보고 있다 | `다음 시즌 보기`를 반복한다 | 한 시즌씩 이동해 최신 시즌으로 복귀한다 | 브라우저 뒤로가기에만 의존하지 않는다 |
테스트 케이스 30건이며 `BLOCKED` 항목은 없다. 요구사항은 프로젝트 오너 승인 완료 상태다.
