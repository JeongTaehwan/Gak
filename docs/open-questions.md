## PROC-OQ-02 · 검증 AI가 [6]을 돌릴 실행 환경 (BLOCKER — 리뷰가 멈춘다)
- 2026-08-23, 통합 타임라인 사이클에서 기록
- 증상: 코드는 문제없는데 [8] 리뷰가 네 번 연속 시작되지 못했다. 전부 실행 환경 문제였다.
  1. `node_modules` 미설치 상태로 빌드 → `next-app-loader` 모듈 없음
  2. Windows에서 `Z:\`(WSL 네트워크 경로)로 빌드 → `EISDIR ... readlink route.ts`
  3. 비대화형 셸이 `~/.bashrc`를 안 읽어 nvm PATH 누락 → Windows npm으로 폴백.
     그 `npm ci`가 `node_modules/.bin`의 POSIX 실행 비트를 지워 **WSL 쪽 빌드까지 깨졌다**
  4. 실행 환경 초기화 오류로 검사 자체를 수행하지 못함
- 원인: 코드는 WSL(ext4)에 있고 검증 AI는 Windows에서 돈다. 두 환경이 같은 트리를
  다른 파일시스템 의미로 본다.
- 방향(사람이 정할 것): ① 검증 AI를 WSL 안에서 실행 ② [6]은 구현 쪽이 돌리고 그 원문
  출력을 검증 AI에 전달, 검증 AI는 리뷰만 ③ 저장소를 네이티브 Windows 경로로 이전
- 판단 근거: [6]은 "코드가 도는 환경 하나에서 재현되면 통과"다. 두 환경이 다른 답을
  내면 그 검사는 코드가 아니라 환경을 재고 있다.
